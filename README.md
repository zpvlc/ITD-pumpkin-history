# Генератор карточек тыковок ИТД + база тыковок

Карточка похожа на оригинальную, но это не так. Так как добавлена строчка "Спасибо от n человек Уровень фонаря x/5" вдобавок свечение сделано неправильно и в будущем может быть будет пофишено

---

## 📁 Структура папки

* `generate_card.py` — основной скрипт генерации карточек.
* `all_pumpkins.json` — база собранных тыкв пользователей (координаты контуров, glow, спасибо, юзернеймы).
* `courtyard.webp` — оригинальный ночной задник замка/двора с CDN ИТД.
* `pumpkin-body.webp` — оригинальная текстура тыквы с CDN ИТД.
* `pumpkin.png` — резервная текстура тыквы высокого разрешения.
* `pangolin.ttf` — оригинальный шрифт `Pangolin`, используемый в интерфейсе события.
* `card_zpvlc.png`, `card_vtfradan.png` — примеры сгенерированных карточек.

---

## Как эта поебота работает

### 1. Сгенерировать карточку по username
```bash
python3 generate_card.py zpvlc
```
Либо с префиксом `@`:
```bash
python3 generate_card.py @vtfradan
```

### 2. Сгенерировать карточку по номеру в базе (хз кто это будет делать)
```bash
python3 generate_card.py 0
```

### 3. Интерактивный режим
Если запустить скрипт без аргументов, он сам спросит ник:
```bash
python3 generate_card.py
```

### 4. Указать свой путь для сохранения
```bash
python3 generate_card.py zpvlc -o /tmp/my_card.png
```
